# Lyre Studio · 21 键演奏台

本地运行的 Windows 游戏乐器演奏器：网页选曲、分声部跟练、任意位置跳转、A–B 循环和慢速练习。每首曲子保存为独立 JSON，添加新曲不需要修改程序。

演奏中可快速切声部、切段落和切歌曲，跳转后立即继续；默认点击开始就起奏。

## 快速开始

需要 Python 3.8 或更新版本。运行只用 Python 标准库，无需安装第三方包或 Node.js。

1. 双击根目录的 **run.cmd**，按 Windows 提示启动。
2. 浏览器会打开 `http://127.0.0.1:8771/`。选择歌曲和声部。
3. 在游戏里打开乐器界面，按 **F8** 或在网页点开始，默认立即起奏。需要切回游戏时可选择等待 3／5／8／10 秒。

只想听曲谱，可运行 `python run.py --demo --port 8772`；试听不创建游戏按键连接。

源码也可以直接运行：

```shell
python run.py --admin
python run.py --demo --port 8772
# 开发时在当前终端运行服务，便于查看错误
python run.py --serve --demo --port 8772 --no-browser
```

## 快捷键

| 快捷键 | 演奏器弹什么 | 跟练方式 |
|---|---|---|
| F5 | 全部声部 | 完整演奏 |
| F6 | 只弹旋律 | 你弹伴奏 |
| F7 | 只弹伴奏 | 你弹旋律 |
| F8 | 开始／暂停／继续 | 开始和继续带倒计时 |
| F9 | 停止并归零 | 释放程序按下的琴键 |
| F10 | 退出演奏台 | 释放琴键及快捷键 |
| Insert／Delete | 上一段／下一段 | 演奏中立即跳转 |
| PageUp／PageDown | 上一首／下一首 | 演奏中立即切歌 |

F5–F7 对游戏输出和网页按钮使用同一套声部选择逻辑。切换保留同一条完整曲谱时间轴，当前按键按原计划松开，下一组音符使用新声部。暂停状态下切换不会擅自开始；倒计时期间切换不会重置倒计时；循环轮次保持不变。网页试听保留已经响起的尾音，只替换尚未响起的预排音符。

切歌和跳转会释放当前音符并立即从新位置继续；变速仍会暂停。默认开启后台游戏演奏：网页获得焦点时向锁定的游戏窗口发送按键消息。游戏是否处理后台消息需实机确认，可关闭开关恢复仅前台发送。纯试听模式的 F5–F7、Insert／Delete 和 PageUp／PageDown 可在网页内使用。

## 功能

- 曲库搜索、上一首／下一首、曲谱导入与导出。
- 进度条、段落跳转、前进／后退 5 秒，演奏中继续播放。
- 旋律与伴奏独立跟练、接下来按键提示、21 键试弹。
- 0.25×～2×速度、A–B 循环、循环当前段落、网页节拍器。
- 原始谱时间坐标：慢放时段落位置保持一致。
- 浏览器只负责操作界面，游戏按键由 Python 独立计时调度。

## 曲谱文件

把 JSON 放入 `songs/`，或在网页导入。首次空曲库会自动添加内置练习短句。

`songs/` 是个人曲库，默认被 Git 忽略；仓库只分发 `src/lyre_studio/examples/practice.json`。本机迁移过来的歌曲仍可直接使用。程序许可证不覆盖你导入的音乐、录音或其他曲谱。

自定义曲库：`python run.py --songs "曲库目录"`，或设置 `LYRE_STUDIO_SONGS`。安装后的默认曲库为用户主目录下的 `.lyre-studio/songs`，不会写入安装目录。

详见 [使用说明](docs/user-guide.md)、[曲谱格式](docs/score-format.md)、[架构与切换规则](docs/architecture.md)。

## 项目结构

```text
.
├── src/lyre_studio/    # Python 演奏器与网页静态资源
│   ├── web/           # 原生 HTML / CSS / JavaScript
│   └── examples/      # 可公开的独立练习谱
├── tests/             # 本机调度、输入、网页接口和试听测试
├── docs/              # 使用、格式和架构说明
├── songs/             # 个人曲库，Git 忽略
├── personal/          # 本机音乐素材与编曲工作资料，Git 忽略
├── run.py             # Python 入口
└── run.cmd            # Windows 启动入口
```

## 上传 GitHub

此目录就是仓库根目录。`.gitignore` 已排除个人曲库、音乐素材、依赖缓存、日志和构建产物。上传前先运行 `git status --short`，确认只包含计划公开的代码与文档，再按 GitHub 新仓库页面的命令设置远程地址并推送。

## 支持范围

Windows 支持真实游戏按键；其他系统支持曲谱检查和网页试听。若游戏以管理员权限运行，演奏器需要匹配权限。后台按键通过窗口消息投递，游戏是否接收需实机确认。程序无法判断是否处于乐器界面；退出乐器前按 F9。两声部同时使用同一个物理琴键时，无法得到两个独立触发。
