# 使用说明

1. 双击根目录 `run.cmd`，打开游戏乐器界面。
2. 网页选择歌曲，确认输出为游戏。默认点击开始或按 F8 即刻演奏；可在“开始前等待”选择 3／5／8／10 秒。
3. F5 完整演奏、F6 只弹旋律、F7 只弹伴奏。切换不会暂停、归零或重新倒计时；你可以弹另一个声部跟练。
4. Insert／Delete 切上一段／下一段，PageUp／PageDown 切上一首／下一首，F8 暂停或继续，F9 停止，F10 退出。

网页声部、段落和切歌按钮与快捷键使用同一套播放逻辑。演奏中跳转会释放当前音符并从目标位置立即继续，不重新倒计时。网页控制时可开启“后台游戏演奏”；程序会向已锁定的游戏窗口发送按键消息。游戏是否接收后台消息取决于游戏输入方式，需要实机确认。关闭该开关则恢复仅前台发送。

## 选曲与练习

将独立 JSON 放入 songs，刷新曲库，或直接通过网页导入。可搜索标题、切换上一首／下一首。每首歌的旋律、伴奏由谱文件明确标注；没有声部标注的谱只提供完整演奏。

拖动进度条或选择段落可以定位。设置 A、B 并开启循环可反复练习；调整速度可慢练。演奏中切歌、跳转和声部切换保持播放，调整速度会暂停。跳出 A–B 循环范围时循环自动关闭。

“只弹伴奏”让你练旋律，“只弹旋律”让你练伴奏。程序不能区分两声部对同一物理按键的独立触发，遇到重叠音需自行调整。

## 网页试听

运行 `python run.py --demo --port 8772`。点击开始允许浏览器播放声音；可以使用 21 键区域试弹、节拍器和循环。试听是合成音色，不等同游戏实际音色。关闭或挂起浏览器可能影响试听调度。

## 常见问题

- 游戏不响：确认已打开乐器，演奏器与游戏权限匹配。后台模式如果无声，关闭后台开关并保持游戏在前台。
- 快捷键注册失败：关闭其他演奏器实例或占用 F5–F10、Insert／Delete、PageUp／PageDown 的软件后重启。
- 切到网页就暂停：检查是否关闭了“后台游戏演奏”；前台模式会在失焦时暂停。
- 调度延迟暂停：恢复前关闭重负载程序，避免补发一串过时音符。
- 需要错误详情：在项目目录运行 `python run.py --serve --no-browser`。

程序仅监听本机地址。退出乐器前按 F9；不使用时按 F10 或网页退出按钮。
